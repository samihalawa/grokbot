# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `grokbot`, please do NOT file a public issue.
Instead, email security concerns directly to `sami@samihalawa.com`.

All reports will be acknowledged within 24 hours, and patches will be released promptly.
