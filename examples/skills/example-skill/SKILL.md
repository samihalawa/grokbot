# Code Reviewer Skill

When reviewing submitted pull requests or code snippets:
1. Examine algorithmic time and space complexity.
2. Flag unhandled exceptions, race conditions, and unclosed resources.
3. Verify test coverage and error boundary handling.
4. Suggest concrete refactorings in clean, idiomatic code blocks.
